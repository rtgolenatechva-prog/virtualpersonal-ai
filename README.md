# JP Franklin Recruitment Platform

Full-stack recruitment platform connecting clients with virtual assistants. Features job listings, candidate matching, interview scheduling, billing management, and a VA/client dual-role dashboard system.

## Stack

- **Frontend:** Next.js (App Router), Tailwind CSS
- **Backend:** Supabase (auth, RLS)
- **Deployment:** Vercel

## Pages

| Page | Description |
|------|-------------|
| `login.html` / `signup.html` | Client and VA role-based authentication |
| `dashboard.html` | Main dashboard (client & VA views) |
| `jobs.html` | Job listings and posting |
| `matches.html` | Candidate/job matching |
| `interviews.html` | Interview scheduling |
| `my-vas.html` | Client's VA management |
| `billing.html` | Billing and subscription management |
| `profile.html` / `settings.html` | User profile and settings |

## Getting Started

```bash
npm install
npm run dev
```
